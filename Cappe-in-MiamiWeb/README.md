# Cappe in Miami Web — v97

## Acabamento visual das armas

Os ícones procedurais ganharam linhas de metal escovado, ranhuras, parafusos, veios de madeira, reflexos de vidro e detalhes de mira. O desenho usa Canvas e não adiciona imagens nem dependências.

## Estrutura desta edição

- index.html contém o jogo e o desenho Canvas.
- js/ reúne sistemas de campanha e expansão.
- css/ e assets/ guardam estilos e recursos.
- cappe-in-miamiWeb.zip contém o pacote executável desta edição.

Para jogar, execute INICIAR_WEB.bat com Node.js 18 ou superior.
